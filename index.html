Generador de Asistencia

Completa tus datos para generar tus enlaces automáticos para Rutinas o Marcadores.

📍 Opción 1: Enlaces de Auto-Envío (Samsung Rutinas / GPS)

Envía el formulario automáticamente sin presionar botones. Ideal para disparar por geolocalización.

⭐ Opción 2: Bookmarklets (Para el navegador)

Guárdalo en marcadores para ejecutarlo manualmente desde la barra superior de Chrome.

📖 Instrucciones de Uso

A. Automatización con Modos y Rutinas (Samsung Galaxy)

  1. Ingresa la URL del Google Form y presiona "Copiar Link Entrada" (Opción 1).
  2. En tu celular entra a Ajustes → Modos y Rutinas → Rutinas (+).
  3. Si: Selecciona Lugar (el hospital o centro) + rango de Horario matutino.
  4. Entonces: Selecciona Sitios web → Abrir enlace web y pega el link copiado.

B. Marcador tradicional en Chrome Móvil

  1. Presiona "Copiar Script Entrada" (Opción 2).
  2. En Chrome toca 3 puntos → Estrella (⭐) para guardar cualquier web.
  3. Toca "Editar" en la barra inferior, escribe Auto Entrada y en URL pega el script.
  4. En el Google Form, escribe Auto Entrada en la barra de direcciones y toca la opción con la estrella (⭐).
💡 Tip para Chrome: Si al tocar la estrella en el navegador no se ejecuta, escribe Auto Entrada y pon un espacio al final antes de tocar la sugerencia.
